3. Circuit Breaker — Resilience Pattern

Per-provider circuit breakers prevent cascading failures. Shared registry ensures all clients see the same state.

stateDiagram-v2
    [*] --> CLOSED

    CLOSED --> CLOSED : success
(reset failure count)
    CLOSED --> OPEN : failure_count >= threshold
(log: circuit_opened)

    OPEN --> OPEN : requests rejected
(fail fast)
    OPEN --> HALF_OPEN : recovery_timeout
expires (60s)

    HALF_OPEN --> CLOSED : probe succeeds
(log: circuit_closed)
    HALF_OPEN --> OPEN : probe fails
(log: circuit_opened)
